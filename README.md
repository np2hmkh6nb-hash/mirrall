# LoopBack

LoopBack is an AI interview review tool. It supports:

- phone number login with verification code
- interview recap input with voice transcription
- resume upload and optimization hints
- interviewer profile analysis
- answer quality scoring and follow-up action plans
- password change in account settings

## Tech Stack

- React
- Vite

## Run Locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173/` in your browser.

## Build

```bash
npm run build
```

## Notes

- Default local password: `123456`
- Verification codes are simulated locally for demo purposes
- The repository is intended to stay source-only; generated artifacts are ignored through `.gitignore`
